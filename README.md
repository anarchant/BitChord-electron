# BitChord Electron

Electron desktop client that wraps the BitChord web version.

A clean YouTube Music client for Windows and Linux, with lossless audio support on Windows.

## Features

- Full BitChord web experience in a native desktop window
- Lossless / Hi-Res playback on Windows
- System tray + close-to-tray
- Discord Rich Presence
- Background playback and media keys
